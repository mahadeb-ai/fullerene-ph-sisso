# Data provenance

The structures and SCC-DFTB property table were supplied as CSIRO fullerene
data. The available source description reports PBC-3 parameters, 300 K
electronic smearing (0.0259 eV), and non-magnetic calculations. Distortion
energy is excess energy relative to planar graphene; Fermi energy is the band-
structure Fermi level. Charges encode anion (-1), neutral (0), and cation (+1).

The source DOI/URL, formal citation, retrieval date, and redistribution license
were not recoverable from the research workspace and require author review.
The source description also does not resolve whether geometries for all three
charge states were independently optimized. Raw data are therefore excluded
from Git history. Checksums and placement instructions are in `data/README.md`.
